## 核心用户流程

### 流程 1：月度考勤核算

1. HR 在“人员管理”维护工号、姓名/别名、部门、策略与标签。
2. 在“导入中心”选择 `.xlsx`、年份、月份和默认应出勤天数。
3. 系统校验文件类型/大小/重复哈希，解析并按工号→姓名→别名匹配。
4. HR 在“异常审核”逐条决定跨日记录归属。
5. 在“核算结果”查看规则轨迹，补充请假/加班/人工调整并确认。
6. 导出 Excel；看板按月份范围和部门聚合趋势与质量。

### 流程 2：招聘候选人推进

1. HR 在“自动化任务”添加 BOSS 账号并完成人工登录。
2. 检查账号状态并同步职位，在“职位管理”查看目标与候选数。
3. 在“候选人”选择推荐、关键词或深度匹配；深度匹配再次确认额度。
4. 勾选发现结果加入候选人库，按平台 ID/组合指纹去重。
5. 在候选人库或流程看板更新阶段、查看详情、创建沟通动作。
6. 外发动作进入确认抽屉，确认账号、候选人、话术和结构化面试信息。
7. 在“确认执行”跟踪逐人结果，在“简历中心”预览/下载版本化 PDF。

### 流程 3：流程自动化

1. 在“流程编排”拖放安全节点并连线。
2. 保存产生不可变草稿版本；校验无环、账号已绑定、发送前有人审节点。
3. 试运行只演练状态机，不创建 RPA/审批工作。
4. 启用版本后选择职位并显式确认正式运行。
5. 运行在人工节点暂停；HR 通过/跳过，失败节点可显式重试。
6. 可暂停、恢复或取消；事件、步骤和任务保留审计链。

## 页面详细设计

### 应用 Shell

- 左侧 244px 深色模块栏，可折叠为 82px；底部显示本地服务状态。
- 顶部 64px 粘性导航，显示当前业务的 6 个功能入口；招聘模块额外显示 Copilot。
- 内容区最大宽度 1660px，桌面左右留白 34px。
- 用户菜单承载角色、模型设置和退出，避免把系统设置塞入业务导航。

### 考勤页面组

- 看板：期间/部门筛选 → 4 个 KPI → 日趋势/部门对比 → 导入质量/待办；数字可下钻。
- 人员：顶部搜索和新增；主体为人员表格；宽弹窗承载主数据、银行和考勤配置。
- 导入：用 STEP 01/02 双面板表达文件与核算期间，主按钮触发同步处理；下方保留历史批次。
- 结果：批次选择与导出在页头，密集表格显示核算构成；人工调整用弹窗渐进披露。
- 异常：按待审核/全部分段，卡片同时展示前一天、当天、打卡文本和决策按钮。
- 规则：策略和标签分栏卡片，点击卡片编辑；说明强调策略、标签、权限互相独立。

### 招聘页面组

- 看板：5 个可点击指标；“今日工作”和“风险提醒”优先于漏斗与趋势；底部是职位目标与自动化日志。
- 职位：账户/状态筛选、职位列表和详情抽屉；同步操作回到自动化安全边界。
- 候选人：候选库和发现入口共页；发现模式按风险渐进增加字段，深度匹配在抽屉二次确认。
- 流程：横向阶段列；拖动后不立即保存，确认层要求填写审计原因。
- 自动化：三级 Tab（账号与任务/确认执行/流程编排）；技术信息可下钻到任务记录。
- 简历：列表显示来源、版本和文件状态；右侧抽屉预览 PDF，历史版本内联切换。当前列表上方保留独立的“智能初筛 · 下一阶段”能力卡，静态展示“上传 Word → 提取初筛标准 → 生成简历评分”，上传按钮保持原生禁用且不触发文件选择或 API；归档视图隐藏该卡片。

## 四态设计

| 页面组 | Loading | Empty | Normal | Error |
|---|---|---|---|---|
| 登录/Shell | 品牌呼吸标记 | 不适用 | 登录表单/应用壳 | 表单内错误 |
| 两个看板 | 首次加载变量，当前多为内容延迟出现 | 引导导入或连接账号 | KPI、任务、图表 | 页面错误 + 重试/保留导航 |
| 列表/表格 | 禁用动作或暂不渲染行 | 跨列空行 + 下一步文案 | 筛选、表格、详情 | 顶部错误条 |
| 文件/自动化 | 主按钮进行中文案、状态轮询 | 引导上传/添加账号/创建批次 | 状态徽标 + 时间线 | 可读错误、等待人工、显式重试 |
| 弹窗/抽屉 | 保存按钮禁用和“保存中” | 局部无记录提示 | 可编辑表单/证据 | 表单错误不关闭上下文 |

观察：现有页面普遍覆盖 Empty/Normal/Error，Loading 的视觉反馈不统一，除应用启动外缺少骨架；建议后续统一为局部骨架，避免整页跳变。

## 视觉规范

### 色彩

| Token | 色值 | 用途 |
|---|---|---|
| Ink | `#0F172A` | 主文字、主按钮、深色卡 |
| Slate | `#334155` | 次级标题与图标 |
| Muted | `#64748B` | 说明文字 |
| Line | `#E2E8F0` | 边框与分隔 |
| Paper | `#FFFFFF` | 面板 |
| Canvas | `#F3F6F8` | 页面背景 |
| Teal | `#0F9F8F` | 品牌、成功、选中、链接 |
| Teal dark | `#087F73` | 悬停与强调 |
| Amber | `#D97706` | 待处理/额度提醒 |
| Red | `#DC4A4A` | 错误/风险/危险动作 |

### 排版

- 字体：Inter、PingFang SC、Microsoft YaHei、system-ui。
- 页面标题 27px / 负字距；卡片标题 15px；正文 13px；辅助 9–11px。
- 英文 eyebrow/panel-kicker 使用 9–10px、粗体、0.11–0.15em 字距，仅作层级标记。
- 数字 KPI 29–31px，使用高字重与紧字距。

### 风格参数

- 4px 为隐含基础单位；常见间距 8/12/16/22/28/34px。
- 面板圆角 14–15px，按钮 9px，输入 9px，品牌标记 13–18px。
- 阴影克制：普通面板仅 `0 1px 2px rgba(...)`；主按钮和悬停卡片使用柔和抬升。
- 无外部 UI 框架，主题自定义程度高；组件语义由全局 CSS 类维护。

## 动效规范

### 基调

低到中等动效，以状态反馈和层级变化为主，不做装饰性页面转场。

| 场景 | 时长/缓动 | 现有行为 |
|---|---|---|
| 文字/边框悬停 | 150–180ms ease | 导航、链接、卡片 |
| 侧栏折叠 | 250ms ease | Grid 列宽过渡 |
| 指标条/趋势柱 | 450–500ms ease | 宽度/高度变化 |
| 弹出菜单 | Transition 类 | 透明度/位移 |
| 启动加载 | 1.2s ease-in-out 循环 | 品牌呼吸 |

建议尊重 `prefers-reduced-motion`；轮询结果只更新受影响卡片，不闪烁整页。

## 响应式策略

- ≥1200px：完整侧栏与两列工作区，保留高信息密度。
- 768–1199px：侧栏默认折叠，指标卡 2–3 列，详情区落到主栏下方。
- <768px：侧栏变顶部/抽屉导航，表格允许横向滚动，主操作固定在可见区域；流程画布和复杂自动化仅提供查看/提醒，编辑建议桌面完成。
- 当前代码已有多处媒体查询和表格滚动；[待确认] 尚无真实移动设备验收证据。
