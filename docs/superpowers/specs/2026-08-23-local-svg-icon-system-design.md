# 人事工作台本地 SVG 图标系统设计

## 目标

在不改变现有导航结构、布局密度和青绿色视觉语言的前提下，替换当前使用的字符、符号和不匹配图形，并为需要视觉提示的位置补充语义准确的简约线性图标。

图标素材优先从 [Iconfont](https://www.iconfont.cn/) 选取同一视觉家族，下载后随前端项目本地保存。运行时不请求外部图标服务。

## 视觉原则

- 全站采用简约线性图标，避免混用 Emoji、文字图标、实心图标和不同描边风格。
- SVG 使用 `currentColor`，由组件所在位置控制默认、悬停、激活和禁用颜色。
- 导航图标尺寸为 20px，按钮和输入框图标为 18px，空状态图标为 28–32px。
- 默认颜色延续现有深灰色；悬停、激活和关键状态使用现有青绿色。
- 图标只用于提高识别效率。普通表格文字操作不机械地增加图标，避免界面变得拥挤。
- 图标保持统一的视觉重量、端点形式、留白和基线对齐。

## 技术方案

新增统一的 Vue 组件 `AppIcon`。组件接收稳定的业务名称，并在内部映射到本地 SVG 路径数据；页面不直接拼接 SVG 字符串，也不依赖字体编码。

图标资源按用途维护在前端源码中：

- `AppIcon.vue`：统一尺寸、颜色继承、可访问性和渲染入口。
- 图标定义模块：保存从 Iconfont 下载并清理后的 `viewBox` 与路径数据。
- 业务页面只传入语义名称，例如 `briefcase`、`calendar-check`、`users`、`upload`。

装饰性图标使用 `aria-hidden="true"`；独立图标按钮必须提供中文 `aria-label`。所有 SVG 在构建后离线工作。

## 图标映射

### 左侧模块导航

- 招聘管理：人才公文包。
- 考勤管理：日历打卡。

### 招聘顶部导航

- 招聘看板：仪表盘。
- 职位管理：公文包。
- 候选人：用户。
- 招聘流程：流程节点。
- 自动化任务：循环任务。
- 简历中心：文档。

### 考勤顶部导航

- 考勤看板：数据图表。
- 人员管理：用户组。
- 导入中心：上传文件。
- 核算结果：计算或核对。
- 异常审核：警告圆形。
- 规则与标签：设置滑杆。

### 页面通用操作

按实际出现位置补齐搜索、筛选、上传、下载、添加、关闭、更多、查看、拖拽、刷新、成功、警告和空状态图标。Copilot 使用星芒图标，账号菜单使用下拉箭头；原有 `×`、`⋯`、`⇧`、`✓` 等字符图形替换为对应 SVG。

## 交互规则

- 导航项图标与文字同步响应悬停和选中状态，颜色过渡控制在 120–180ms。
- 图标按钮保持现有点击热区，不因 SVG 的视觉尺寸缩小可点击范围。
- 禁用状态由父级颜色和透明度控制，不在 SVG 内写死颜色。
- 加载状态继续使用文字反馈；只有已有明确旋转交互时才使用加载图标，避免无意义动画。

## 范围边界

- 不调整左侧栏、顶部导航、卡片、表格和页面信息架构。
- 不更换品牌标识、字体或主题色。
- 不新增外部运行时依赖，不使用 Iconfont 在线 CSS、在线脚本或 CDN。
- 不给每个文本链接或表格操作强制添加图标。
- 不改动后端接口和数据库。

## 验收标准

- 页面中不再出现用于充当图标的 Emoji 或几何字符。
- 招聘与考勤导航的图标语义明确且属于同一线性风格。
- 默认、悬停、激活、禁用状态均能通过 `currentColor` 正确呈现。
- 图标按钮具备可访问名称，装饰性图标不会被屏幕阅读器重复朗读。
- 登录页、两套导航及主要招聘和考勤页面在 Edge 中无 SVG 加载错误。
- 前端单元测试与生产构建通过，Django 静态资源重新收集后页面可以正常离线加载。
