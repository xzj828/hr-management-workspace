# 西鸣人事管理系统导航与公共界面重设计

日期：2026-08-22  
状态：用户已确认设计，待书面复核

## 1. 目标

重新设计 Vue 3 人事工作台的公共布局，使导航层级符合实际使用方式：

- 左侧深色导航栏只负责切换一级业务模块；
- 内容区顶部使用横向文字导航展示当前模块的细分页面；
- 页面标题和操作回到正文区域；
- 减少常驻按钮和视觉噪声；
- 保留现有路由、页面能力和整体视觉风格。

参考方向为用户提供的腾讯云顶部导航截图：单行、纯文字、清晰当前项、右侧保留少量工具入口，但不复制腾讯云品牌或页面内容。

## 2. 设计范围

本次只调整公共布局、导航交互和相关样式，不修改招聘、考勤业务 API，也不新增招聘业务功能。

专门的手机端布局不在范围内。系统按 Windows 电脑端工作台设计；当桌面窗口变窄时，只提供必要的横向滚动和防溢出处理，不把侧栏改成底部导航。

## 3. 信息架构

### 3.1 左侧一级模块导航

左侧深色栏保留当前宽度、品牌区、运行状态和收起功能，导航内容仅包含：

```text
招聘管理
考勤管理
```

两个入口沿用现有侧栏导航项的图标、文字、悬停和选中样式。点击模块时进入该模块上次访问的细分页面；当前会话没有访问记录时进入对应看板。

### 3.2 招聘顶部导航

```text
招聘看板 | 职位管理 | 候选人 | 招聘流程 | 自动化任务 | 简历中心
```

### 3.3 考勤顶部导航

```text
考勤看板 | 人员管理 | 导入中心 | 核算结果 | 异常审核 | 规则与标签
```

顶部导航从左侧栏右边开始，只属于内容区。使用白色背景、细底边、纯文字链接。当前项使用青绿色文字和 2px 底部指示线，不使用胶囊按钮。

## 4. 公共布局

### 4.1 左侧栏

- 深蓝黑背景和现有品牌标识保持不变；
- 展开时显示“招聘管理 / 考勤管理”完整名称；
- 收起时只显示模块图标；
- 底部保留本地服务运行状态和收起按钮；
- 侧栏贯穿整个窗口高度。

### 4.2 顶部栏

顶部栏高度约 64px，分为两部分：

- 左侧为当前模块的六个细分页面导航；
- 右侧为按需出现的 Copilot 入口和用户区域。

顶部栏不再显示页面标题和组织说明。细分导航始终单行，空间不足时允许在导航区域内横向滚动，不折行、不压缩账号区域。

### 4.3 用户区域

常驻状态只显示头像和姓名。点击后打开轻量菜单，包含：

- 当前账号与角色；
- 模型配置入口；
- 退出登录。

退出不再作为常驻描边按钮。菜单支持点击外部关闭和 Escape 关闭，并保留键盘焦点状态。

### 4.4 Copilot 入口

Copilot 只在招聘模块显示，使用简洁文字或星光图标入口，不使用高强调主按钮。点击后继续打开现有招聘 Copilot 抽屉。

### 4.5 页面正文

页面标题、说明和该页主要操作位于正文顶部。每个页面最多保留一个常驻主操作；筛选、批量操作、导出和设置等次要能力按需放入下拉菜单、抽屉或选择状态工具条。

本次不强制重写所有业务页面，只建立公共布局规则，并确保现有页面在新布局下正常显示。

## 5. 视觉语言

- 保留深蓝黑侧栏、白色顶部栏、浅灰页面背景和青绿色品牌色；
- 减少阴影、装饰性块和高对比按钮；
- 主要依靠间距、细边框、字号和文字颜色建立层级；
- 顶部导航字号约 13–14px，项目间距宽松；
- 当前项清晰但克制，使用文字色和底部细线表达；
- 内容区继续使用现有白色面板，但避免无意义的卡片嵌套。

## 6. 组件与状态

公共布局继续由 `AppLayout.vue` 负责，但导航数据保持在 `navigation.js` 中作为唯一来源。

需要维护两类状态：

- 当前模块：由路由 `meta.module` 推导；
- 模块最后访问路由：在当前浏览器会话内记录，模块切换时优先返回该路由。

左侧模块入口使用 `modules` 数据；顶部细分导航使用 `navigationForModule(currentModule)`。现有业务路由名称和 URL 不变，避免破坏书签、重定向和页面接口。

用户菜单开关、Copilot 抽屉开关和侧栏收起状态互不耦合。切换模块或路由时关闭用户菜单，避免悬浮层残留。

## 7. 错误与降级处理

- 未识别的路由模块回退到考勤模块；
- 模块没有有效的上次访问路由时回退到模块看板；
- 顶部导航超出可用宽度时只在导航区域横向滚动；
- 用户信息尚未恢复时显示头像占位，不阻塞导航渲染；
- Copilot 配置加载失败只影响抽屉，不影响公共导航和其他页面。

## 8. 测试与验收

自动化测试覆盖：

- 招聘和考勤路由正确映射到一级模块；
- 左侧只显示两个一级模块入口；
- 两个模块分别显示正确的六个顶部导航项；
- 模块切换默认进入看板，并能返回当前会话上次访问页面；
- 当前顶部导航项具有明确选中状态；
- 用户菜单、退出和 Copilot 入口按设计出现；
- Vue 测试与生产构建通过。

浏览器验收覆盖：

- 登录后分别打开招聘和考勤模块；
- 左侧栏贯穿全高且只展示两个模块；
- 顶部导航从侧栏右边开始、保持单行；
- 页面标题位于正文而不是顶部栏；
- JS/CSS 静态资源返回正确 MIME 类型，页面无空白；
- 典型 Windows 桌面宽度和较窄桌面窗口下均无导航重叠。

## 9. 明确不做

- 不复制腾讯云品牌、配色或业务内容；
- 不新增手机端底部导航；
- 不改变招聘与考勤业务路由；
- 不在本次重写所有业务页面；
- 不把六个细分功能重新放回左侧栏；
- 不把“招聘管理 / 考勤管理”继续放在顶部栏。
