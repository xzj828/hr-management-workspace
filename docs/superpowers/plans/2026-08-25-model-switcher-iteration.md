# 多模型切换迭代计划

> 日期：2026-08-25
> 状态：已完成并通过统一验收
> 范围：个人模型档案、Shell 快速切换、管理后台模型管理；不新增聊天或简历评分能力

## 产品目标

把误导性的“Copilot”入口改为“切换模型”。用户可以在任何招聘页面快速选择已保存模型，也可以新增自定义 OpenAI 兼容模型；管理人员在管理后台看到同一套模型档案并完成编辑、测试与切换。

## 验收标准

- 顶栏明确显示“切换模型”，全局不再把模型连接配置称为 Copilot。
- 无模型时能直接新增；有模型时可在两次点击内完成切换，当前项同时有文字和图标状态。
- 可以保存多个自定义模型；名称、API 地址、模型名称和密钥均有服务端校验。
- API Key 明文不出现在任何 GET 响应、前端持久化或日志中；编辑时留空沿用原密钥。
- 首个档案自动成为当前模型；切换幂等且每用户最多一个活动档案；用户不能读取或修改他人档案。
- 入队或无配置任务首次绑定时从 `UserModelCredential` 捕获默认连接；既有评分/抽取 Worker 只使用任务快照，切换与重试不漂移。
- 模型 A 下创建的任务在切换到 B 后仍使用 A 的不可变加密快照；任务 API 不返回连接或密钥快照。
- 默认只允许公网 HTTPS 模型地址；内网模型必须由部署管理员显式允许，连接前后都不会把密钥发给未通过校验的对端。
- 菜单和抽屉具备 Loading、Empty、Normal、Error，支持 Escape、遮罩关闭和窄屏单列。

## 风险与回退

- 风险：新档案与旧单凭证发生漂移。通过单一事务服务同步活动档案与兼容投影，并覆盖旧端点回归测试。
- 风险：误切模型影响未来任务。切换后在顶栏即时显示当前名称；历史任务仍读取自身已存模型快照。
- 回退：移除新前端入口后旧凭证端点仍可作为默认连接入口；迁移会新增模型档案、修复不完整活动投影，并为可恢复 AI 任务回填快照，无配置任务安全回到 `WAITING_CONFIG`。
