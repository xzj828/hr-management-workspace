# 招聘任务卡片区独立滚动

日期：2026-08-27  
状态：已完成

## 问题

- 招聘任务集合已经按单次运行长期展示多张卡片，但卡片网格仍按内容自然增高。
- 当任务数量增加时，整个文档被纵向撑长，二级导航、页头和筛选区会随页面滚动离开视口。

## 设计决策

1. 只对招聘任务集合路由锁定应用壳层为当前动态视口高度，不改变任务详情或业务结果页面的长页面行为。
2. 集合页使用“二级导航、页头、剩余高度任务面板”三段布局；所有中间容器显式允许子项收缩。
3. 筛选区固定在任务面板顶部，卡片列表占用剩余高度并使用独立纵向滚动；外层页面不随卡片数量增加而增高。
4. Loading、Error、Empty、筛选无结果和同步警告状态都保持在同一任务面板高度边界内。

## 验收标准

- [x] 1440×900 下展示现有 9 张任务卡时，外层文档高度不超过视口。
- [x] 卡片列表的滚动高度大于可见高度，鼠标滚轮可浏览后续卡片。
- [x] 滚动卡片列表时，结果中心二级导航、招聘任务页头和筛选区位置不变。
- [x] 搜索、状态筛选、类型筛选和卡片详情入口行为保持不变。
- [x] 前端专项测试和生产构建通过。

## 实现边界

- 不修改任务 API、持久化模型、轮询频率或任务排序。
- 不把任务详情页和业务结果页强制改成单屏滚动容器。
- 不创建子 Agent。

## 验证记录

- 浏览器运行态（1440×900、真实 9 张卡）：文档高度与视口均为 900px，页面滚动位置保持 0。
- 卡片滚动区可见高度 428px、内容高度 1327px；鼠标滚轮后内部滚动位置从 0 变为 420px，筛选区顶部位置保持 298px。
- 卡片保持 410px 完整高度，未通过压缩卡片来伪造单屏布局；浏览器控制台无错误。
- 前端全量 Vitest：43 个测试文件、269 个用例全部通过；Vite 生产构建通过。
