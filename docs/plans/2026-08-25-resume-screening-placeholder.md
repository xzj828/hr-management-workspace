# 简历智能初筛前端占位迭代

日期：2026-08-25
状态：已完成

## 决策

Word 用户画像/招聘需求上传、初筛标准提取和简历评分整体属于下一阶段，不参与当前 BOSS 职位同步、候选人发现、沟通或简历归档流程。当前版本只在“简历中心”保留清晰、稳定且不可操作的前端位置。

## 交互方案

- 在当前简历页头与简历列表之间展示“智能初筛 · 下一阶段”能力卡。
- 卡片展示三步：上传 Word、提取初筛标准、生成简历评分。
- 保留“上传 Word（暂未开放）”原生禁用按钮；不绑定点击事件，不创建文件输入，不发起 API 或模型调用。
- 文案明确该能力不影响现有 PDF 简历的预览、下载、归档和版本管理。
- 归档记录视图隐藏能力卡。
- 当前文件状态不再使用容易被理解为正在排队的“待 AI 评估”作为页面主状态。

## 非目标

- 不新增 Word 上传 API、文件模型或解析依赖。
- 不新增评分接口、Prompt、模型调用或假数据结果。
- 不新增路由或空白子页面。
- 不改变现有 BOSS 自动化和简历文件操作。

- [x] 在实际页面验证桌面与窄屏布局。

## 验收标准

1. 用户能同时看见“智能初筛”“下一阶段”和“Word → 标准 → 评分”三步关系。
2. 禁用按钮不能通过鼠标或键盘触发任何上传、弹窗或网络请求。
3. 正常列表、加载、空态和错误态都保留能力卡；归档记录不展示。
4. 现有 PDF 预览、下载、归档、恢复和版本切换不受影响。
5. 卡片在窄屏纵向排列，不给现有表格增加额外横向溢出。

## 验证结果

- 定向组件测试：4/4 通过。
- 完整前端测试：29 个测试文件、88 项测试全部通过。
- 生产构建：通过；仅保留既有的大体积 ECharts 分包提示。
- 真实页面：当前简历页展示能力卡和三步关系；禁用按钮无事件；归档视图隐藏；680px 视口无页面横向溢出；控制台无错误或警告。
