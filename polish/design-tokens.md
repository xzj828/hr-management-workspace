# Design Tokens（从 DESIGN.md 提取）

## 颜色

| 角色 | 色值 | 用途 |
|---|---|---|
| primary | `#0f9f8f` / `#087f73` | 链接、选中、成功与焦点 |
| background | `#f3f6f8` | 页面背景 |
| surface | `#ffffff` | 主面板、工具栏、浮层 |
| foreground | `#0f172a` | 标题和主要文字 |
| muted | `#64748b` | 辅助说明 |
| border | `#e2e8f0` | 分割线和输入边框 |
| warning | `#d97706` | 待处理和风险 |
| destructive | `#dc4a4a` / `#b83f4b` | 错误和确认删除 |

## 字体

| 层级 | 字体族 | 字号 | 字重 |
|---|---|---|---|
| H1 | Inter / 中文系统字体 | 27px | 700 |
| H2 | 同上 | 15–20px | 700 |
| Body | 同上 | 13px | 400–600 |
| Control | 同上 | 12–13px | 600–700 |
| Meta | 同上 | 10–11px | 400–700 |

## 间距

基础单位：4px。刻度：8 / 12 / 16 / 22 / 28 / 34px。页面栈 22px，区块内部 8–16px。

## 圆角

| 元素 | 圆角 |
|---|---|
| 按钮/输入 | 9px |
| 主面板 | 15px |
| 小提示/状态 | 6–9px 或胶囊 |

## 阴影

| 层级 | 阴影 |
|---|---|
| 普通面板 | `0 1px 2px rgba(15,23,42,.025)` |
| 浮层 | `0 18px 48px rgba(15,23,42,.15)` |

## Do / Don't

- Do：单一主动作、连续业务流、扁平列表、局部错误、渐进披露技术详情。
- Don't：卡片墙、按钮墙、嵌套边框、多个品牌绿、8px 交互文字、普通卡片上浮。
