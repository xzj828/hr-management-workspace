# Sprint Contract: 招聘看板

## Baseline

- 总分：13/20
- 最差维度：Compliance / Craft / Coherence（3）
- 截图：`polish/baseline/recruitment-dashboard-before.png`

## Gap 分析

- KPI、风险、岗位、漏斗、趋势、任务的视觉权重较接近，缺少主次。
- 部分小卡片和入口按钮形成轻度卡片墙。
- 与考勤看板相比，页面缺少一个明确的主分析区和次要信息区。

## 验收标准

1. 保留一个主 KPI 带和一个主分析区域，次要风险/任务使用紧凑列表。
2. 面板边框、圆角、标题与考勤看板完全同源。
3. 岗位和任务行使用分隔线，不用逐行小卡片。
4. 全局看板语义、跳转和空态不回归。

## PASS 阈值

总分 ≥16/20，且无单项 ≤2。

## 改动边界

只改视觉与布局，不改聚合指标、链接和 API。
