## 方案 C 可执行差距

1. 过滤器应在桌面保持单行三列，KPI 紧接其后形成一块轻量连续表面。
2. 四个 Tab 应在桌面始终单行，使用细下划线和小计数，不再形成 2×2 大按钮。
3. 去掉重复英文 eyebrow / panel kicker，降低视觉噪音。
4. 人工事项改为表格式队列：事项、类别/对象、上下文、时间、状态、动作稳定对齐。
5. 任务结果保留真实“双区”结构，但列表改为更轻的行分隔与细进度线。
6. 候选排名继续使用真实连续表格，强化筛选、选中行与操作列的方案 C 暖灰/青绿层级。
7. 招聘进度改为横向阶段分布，直接使用后端候选应聘阶段统计；岗位目标与当前数据放在同一底部摘要区。
8. Loading / Empty / Error 继续保留骨架和恢复动作，但压缩无效留白。
